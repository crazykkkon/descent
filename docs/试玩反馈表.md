# 《坠井者》试玩反馈表（井的契约）

试玩链接：https://crazykkkon.github.io/descent/

请连续玩 **3 局**（死了也算一局）。每局结束后，结束画面或死亡画面下方会显示"你的契约记录"，**截一张图**发给我们。

## 每局玩完回答（一两句话就行）

1. 第 1 层楼梯口，你签了契约吗？**签 / 没签的理由是什么？**
2. 签之前，你有没有看自己的生命和攻防？有没有在心里算一下？
3. 下到第 2 层看到地图后，你的想法变了吗？是地图上**哪个细节**让你改了主意（或者没改）？
4. 如果签了：你最后是守约还是喝了血瓶？喝之前犹豫了吗？
5. 出口结算里"守约最多能带出多少、不管契约最多多少、你带出多少"这一行，你看了以后觉得自己赢了井，还是输给了井？

## 三局都玩完再回答

6. 三局里你的选择一样吗？如果不一样，是什么让你换了做法？
7. 有没有哪一刻你觉得"这个契约是白送的"或者"这个契约根本不能签"？
8. 你还想要别的契约条件吗？比如"不开骨门""出口时生命至少多少"。
9. 哪里看不懂、哪里让你觉得别扭？

---

**给我们自己看的**：最想看到的是同一个人在不同局里分别**拒签、守约、主动毁约**，而且能说出是地图上的什么让他改了主意。比"有多少人签约"更重要。
